!32 0 alignment panels
There are 3 pages on the alignment panel. Use L or R clicks to switch between them.
NOTE: Parameters on this panel are selected differently from other text fields outside the panel.
      Use the up/down arrows to highlight fields, and the left/right arrows to change fields.
--------
1st page
--------
The 1st page sets up the alignment. If the orientation is completely different from the template,
you can rotate in steps of +- 90 degrees around x, y, or z. Alternatively, you can swap the z
order, which changes the parity of the coordinate system.  A "hidden feature" (not recommended unless
angles are small) is the use of a "deck-of-cards" alignment matrix in place of the affine one. Access
this feature with control-A.
  Two filters are provided: 1) a "rolloff" filter to reduce long-range intensity variations by
dividing the image by a smoothed version of itself, and 2) a overlay filter to remove signal
outside the brain (USE A STANDARD TEMPLATE!). The overlay can be loaded using the "-o" option on startup
or simply read from the file ".ovl" using the read key/button ("r").
  Downsampling is useful for speeding alignment for affine transformation, but don't use downsampling
for non-linear warps unless image resolution and contrast are quite good. Generally, use the default
down-sampling options. Employ multi-resolution alignment by using "A" or the R button on the
"auto-alignment affine" text field.
--------
2nd page
--------
The 2nd page contains the affine alignment parameters. Parameters can be individually selected or
removed from automated alignment by hitting the "x" key; an all/none selection is provided below
the alignment parameters. To see and change parameter increments for manual adjustment, use the TAB key
to switch between adjusting values versus adjusting increments. When would one want to remove parameter?
Consider this case: automated alignment is applied using a high-resolution anatomical image with good
contrast. Then, this alignment is used as the basis for aligning EPI data with the same slices.
Because the slice selection process is identical for the two sequences, there is no need to adjust
the z position or the z size (doing so with low-contrast data likely will lead to error). So, remove
z and size-z, and adjust other parameters to account for slice-specific shifts and distortions.
--------
3rd page
--------
This page contains X,Y,Z distortion fields. Select fields by highlighting and hitting "x".
When "A" is used (or R-mouse click on "auto-align" text field), the current basis grid and rigidity are used.
When "a" or L-mouse click is used, adjustments start from the current down-sampling setting (e.g., 8)
and proceed to finer grid sizes until 2x undersampling is reached.
The "smooth|stiff" setting adjusts the penalty distortion between a setting of "smooth"
(the penalty depends upon the 2nd derivative of the distortion fields) and "stiff" (penalty depends
only upon 1st derivative) or an admixture of the two. To visualize distortion fields, select the
"individual/template" field to step past these options and show the distortion fields. Remember that
the space bar toggles between individual/template.

__________________ COLOR BAR ____________________________________
The colorbar depicts activation overlays using either a linear
scale ("-a" option from command line) or a log-10 scale ("-p"
from command line). Note that all linear maps are subject to an
implicit filter from the preceding log-10 map, under the assumption
that the log-10 map represents p values and the following linear
map shows an index like percent signal change.
OPTIONS:
-  When more than 1 activation map is loaded, use the +/- keys
   to page through different activation maps.
-  To change the lower/upper limit of the colorbar, position the
   cursor near the lower/upper range and use the up/down arrows.
-  To set the lower/upper range, click near the lower/upper limit
   using the L BUTTON.
-  To expand the lower/upper range, click near the lower/upper limit
   using the R BUTTON.
-  To select just one tail of the distribution, click on either
   the "+" or "-" fields above the colorbar using the L BUTTON.
-  To switch the +/- color fields, click on these fields using
   the R button. This is sometimes useful to account for a sign
   change in the map; e.g., "+ activation" procudes "-" signal
   changes using MION.
-  To toggle through +/- colorbars with different color maps, use
   the left/right arrows with the cursor on the colorbar.

!4 128 Selectable-text N
This option generates new wire frames (to draw a square overlay, click the R mouse button
and drag down and to the right).  When an activation map is present, use of the L button
will create an overlay from a activation island, and the R button will prompt for a wire frame.
  A wire frame is useful in two ways: 1) to visualize regions of interest without covering
them by an overlay, and 2) to generate overlays of arbitrary shape.
  Wire frames are drawn using Bezier curves. Every 4 points defines a smooth curve, so the
first wire segment does not appear until after 4 points are marked (L mouse button).
Subsequently, only 3 points are needed, since the 4th point ends the previous segment.
When a wire segment is nearly completed, you can choose to end it or close it; the latter
option connects to the first point of the first segment and additionally generates an
overlay by filling the closed wire frame.
*** Currently, wire frames can only be drawn on the x-y plane (mosaic or 3-plane mode). ***

!4 256 Selectable-text r/R
This option reads an overlay (r) or wire frame (R) from files .ovl or .wire,
respectively.  Use the L button for overlays and the R button for wire frames.
Overlays are based upon voxel indices, whereas wire frames are based upon spatial
coordinates. Wire frames can be used across resolution scales, whereas overlays
are fixed to a specific grid.
  The format of overlay files consists of either 3 or 4 entries per line in an
ASCII file, with the first 3 entries indicating the (i j k) voxel indices
corresponding to the (x y z) axes. The 4th entry, if present, is the voxel weight
and should be between 0 and 1. In all ROI calculations, weighted summations are
performed across the overlay.
  A wire frame file is an ASCII-formatted table of Bezier control points, with each
listing an (x,y,z) coordinate position followed by a "1" (pen down) or "0" (pen up),
with the latter indicating the end of a wire frame.

!4 65536 Selectable-text i
This selection automatically sets the contrast/brightness levels of the image display.

!4 -2147483648 Selectable-text Do-Everything
"Do Everything" button.
Ok - this button doesn't "do everything".  What is does is this:
 1) apply the rolloff filter using a smoothing kernel equal to 1/4 FOV,
 2) apply the overlay filter if an overlay is loaded,
 3) perform affine alignment using the multi-resolution approach,
 4) remove the overlay filter,
 5) perform non-linear alignment using the multi-step approach.
You should roughly position the image volume prior to alignment.
Also, set the desired parameters for alignment, including:
  - affine parameter of interest            (default = all)
  - non-linear alignment fields of interest (default = all)
  - rigidity.
