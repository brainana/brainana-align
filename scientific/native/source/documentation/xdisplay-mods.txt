addition 3/23/2005 Whereas using the left mouse button on the activation tails
		   region ('+' or '-' above colorbar) selects the + or - tail,
		   using the middle or right buttons changes + to - and vice
		   versa. This is way to switch between color schemes for
		   + and -, so that "activation" with IRON, when signal goes
		   down, can appear as red to yellow.
