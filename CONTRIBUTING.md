# Contributing

Read [build instructions](docs/building.md) and [AGENTS.md](AGENTS.md). Keep app behavior
and scientific source separate from packaging changes. Add regression evidence for
physical coordinates, region axes, registration/session/export or UI changes. Keep
private subjects and credentials out of commits. Never mark GPU/native-platform checks
passed from source inspection or DOM tests. Publication instructions are in
[docs/publishing.md](docs/publishing.md).
